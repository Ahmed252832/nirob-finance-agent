Run from the app root after starting the launcher. Set NIROB_MODEL_KEY_FILE to the absolute path of data/model.key for model evaluation, then run node evaluation/evaluate_agent.mjs. Run node evaluation/evaluate_ocr.mjs for the two clean bill fixtures. These scripts overwrite their evaluation JSON files; preserve submitted results if comparing runs. Browser QA requires a separate test database and Chrome CDP virtual authenticators; its procedure and raw results are disclosed in SECURITY.md.

To reproduce browser QA, start the server with a fresh NIROB_DATA_DIR and the local model running; launch Chrome with a separate temporary user profile and --remote-debugging-port=9234 at http://localhost:4177. Then run node evaluation/browser-qa.mjs. It registers virtual keys, modifies only that demo database, and overwrites browser-results.json/overview.png. Do not run it against a user workspace.
