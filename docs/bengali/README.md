# Bengali concept guides

These are the previously delivered Bengali planning documents, included for project context:

1. `Earned_Autonomy_Wallet_Revised_Bengali_Guide.pdf` — early revised non-blockchain concept.
2. `Earned_Autonomy_Wallet_Bank_Card_Advisor_Bengali_Guide.pdf` — expanded bank/card/advisor discussion.
3. `Earned_Autonomy_Wallet_Account_Card_Integration_Guide_BN.pdf` — later account/card integration concept guide.

They predate the final v3.3 chat, workspace controls and measured 100-case benchmark. They have not been rewritten as part of the GitHub upload. For the implementation that actually exists, use the root README, ARCHITECTURE, SECURITY, EVALUATION and PERSONAL_WORKSPACE documents, plus the current media.

All payments in the current app are simulated. Real bank/card integration discussed in these guides is future work requiring authorization; it is not enabled by adding an account number. The proposed competition category is Topic A. No Topic F on-chain-compliance claim is made.
