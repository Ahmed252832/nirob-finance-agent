# Demo and presentation guide

Recorded demo is an automated capture of the real browser UI, with synthetic money and a disclosed virtual authenticator. There is no physical-fingerprint claim. No app action is faked in the recording.

1. Register a passkey and explain local user verification.
2. Give a monthly review/budget goal; show model-selected tools and results.
3. Calculate a savings-aware budget and save the spending limit.
4. Upload the sample English bill; review OCR fields and save.
5. Ask the agent to prepare the electricity bill.
6. Mark the draft correct to show feedback; explain that this does not approve payment.
7. Review the exact payment; verify the passkey; show the posted demo expense.
8. Add a cash expense.
9. Generate an unknown request, block it, and inspect audit integrity.

For a live presentation use a fresh local data folder and your own platform authenticator. Tell the judges if Windows asks for a PIN instead of fingerprint. If the local model fails, report that failure; do not present precomputed fixture output as live AI.

Suggested deck timing: problem 40s; workflow 50s; agent 70s; budgeting/OCR 60s; security 70s; trust 45s; evidence 50s; competition/delivery 35s. Total about 7 minutes.
